# keisanki（アプリ置き場）

PWA（ブラウザで動き、iPhone のホーム画面に置けるウェブアプリ）の練習用の置き場。
いまは2本入っている。

| アプリ | 住所 | 中身 |
|---|---|---|
| 計算機 | https://terakoshi.github.io/keisanki/ | 1本目。ふつうの電卓 |
| 電波マップ | https://terakoshi.github.io/keisanki/denpa/ | 2本目。家のWi-Fiの電波を色つきの間取り図にする |

---

# 1本目・計算機

作成: 2026-08-25

## できること

- 足す・引く・かける・わる、％、プラスマイナスの切り替え、小数点
- 「AC」で全部消す／数字を入れた後は「C」でその数だけ消す
- **表示部分を左になぞる**と、1文字だけ消える（打ち間違いの取り消し）
- **表示部分を軽くたたく**と、答えをコピーする
- パソコンではキーボードでも打てる（数字 / + - * / / Enter＝イコール / Backspace＝1文字消す / Esc＝全消し）
- 0で割ったら「エラー」と出る（何か押すと元に戻る）
- 桁が多いときは自動で文字を小さくして、3桁ごとにカンマを付ける

## ファイルの中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。見た目も計算も全部この1枚に入っている |
| `manifest.webmanifest` | ホーム画面に置いたときの名前・色・アイコンの設定 |
| `sw.js` | 電波がなくても開けるようにする裏方 |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン画像 |

## 動かし方

### パソコンで見るだけ

`index.html` をダブルクリックする（ブラウザで開く）。計算はこれで全部できる。

### iPhone のホーム画面に置く

1. iPhone の **Safari** で https://terakoshi.github.io/keisanki/ を開く
2. 下の共有ボタン → 「ホーム画面に追加」

アイコンが並び、タップするとアドレスバーのないアプリのように開く。https なので「電波がなくても開ける」機能も働く。

### （参考）パソコンから直接配る方法

公開したくない試作を iPhone で見たいときは、同じWi-Fiのパソコンから配れる。

```
python -m http.server 8000 --directory "C:\Users\terak\claude_workspace\work\副業\apps\keisanki"
```

`ipconfig` で調べたIPアドレスを使って、iPhone の Safari で `http://そのIP:8000` を開く。
**ただし iPhone 側の設定で「安全でない接続（http）」が拒否されることがある**（2026-08-25 に実際に詰まった）。
その場合は上の GitHub Pages 方式を使うほうが早い。

# 2本目・電波マップ（`denpa/`）

作成: 2026-08-24

家の中を歩きながら「いまいる場所」を押していくと、そこの電波を測って色をつける。
歩いた範囲の形がそのまま間取りになり、電波の良し悪しが色で分かる。

**https://terakoshi.github.io/keisanki/denpa/**

## できること

- 地図を押すと、その場所の電波を1〜2秒で測って **色の丸** を置く
- 置いた点のまわりがにじんで、**緑＝よく届く／黄＝ふつう／橙＝弱い／赤＝かなり弱い** で塗られる
- 歩いた範囲のふちに線が引かれ、**家の形（間取り）が浮かび上がる**
- 「かべ」を指でなぞって引ける（まっすぐに近いと、たて・よこに自動で揃う）
- 「へや名」で部屋の名前、「ルーター」でWi-Fi親機の場所を置ける
- 「消す」で1つずつ消す／「1つ戻す」でやり直す
- 「画像で保存」で、色の見本つきの1枚の絵にできる（iPhoneでは共有シートが出る）
- 描いたものは自動で残るので、アプリを閉じても消えない

## 電波の測り方（ここが大事）

**ブラウザには「Wi-Fiの電波が何本か」を直接読む仕組みがない。**
iPhone でも Android でも、ウェブページからは電波強度（dBm）を取れない。

そこでこのアプリは、ごく小さなファイル（`ping.txt`）を何度もやりとりして、

- **返事の速さ**（何ミリ秒で返ってくるか）
- **ゆらぎ**（速さのバラつき）
- **とぎれ**（返事が来なかった割合）

の3つを測り、0〜100点の「電波の良さ」に直している。
電波が弱い場所ほど返事が遅れてバラつくので、実際の強さとだいたい合う。

**ただし、これはインターネットまでの通信の良さなので、Wi-Fiの電波そのものとは完全には一致しない。**
つながっていないと測れないし、回線が混んでいる時間帯は全体的に低めに出る。
そのときは ⚙ の **「手動で強さを入れる」** を入にすると、押すたびに
iPhone の画面上のアンテナ本数（4本〜圏外）を選ぶ形になり、電波が無くても間取りは描ける。

## 設定でできること

| 項目 | 意味 |
|---|---|
| 手動で強さを入れる | 測らずに、アンテナ本数を自分で選ぶ |
| 地図の広さ | 地図の横はばを 6〜20m から選ぶ。家の大きさに合わせる |
| 1点の広がり | 1回の測定が色を塗る範囲。点をこまめに置くなら「せまい」 |
| ていねいに測る | 測る回数を増やす。正確になるが少し時間がかかる |

## ファイルの中身（`denpa/`）

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。見た目も測定も地図も全部この1枚 |
| `ping.txt` | 電波を測るために、何度も取りに行く小さなファイル |
| `manifest.webmanifest` / `sw.js` | ホーム画面用の設定と、裏方 |
| `icon-*.png` / `apple-touch-icon.png` | アイコン画像 |

## 使うときのコツ

- **1〜2歩ごとに1回**押すくらいが、ちょうどよい細かさ。
- 部屋の真ん中だけでなく、**すみっこや廊下、トイレ・風呂の前**も測ると形がはっきりする。
- 電波が悪い場所を探すのが目的なので、**弱そうな部屋こそ多めに**測る。
- 先に「かべ」で家の形を描いてから測ると、自分がどこにいるか分かりやすい。

# アプリを足すときに読むメモ

**新しいアプリをこの置き場に足す前に、まずここと既存の `sw.js` を読むこと。**
下の「事故が起きた場所」は、実際に壊してから気づいたもの。

## 1本足すのに必要なもの

`新しい名前/` というフォルダを作り、その中に一式そろえる。
既存アプリのファイルは書き換えない。これでホーム画面に別アイコンとして並ぶ。

```
新しい名前/
  index.html              ← アプリ本体。見た目も中身も1枚に入れている
  manifest.webmanifest    ← ホーム画面の名前・色・アイコンの設定
  sw.js                   ← 電波がなくても開けるようにする裏方
  icon-192.png / icon-512.png / apple-touch-icon.png
```

アイコンは Python の Pillow で作れる（`pip install pillow`）。

## 事故が起きた場所 ―― 裏方（`sw.js`）の掟

同じ置き場のアプリは、**保存版のしまい場所を共有している**。油断すると互いを壊す。

- **自分のフォルダ直下以外の要求には手を出さない。**
  ふつうに書くと、上のフォルダの `sw.js` が下のアプリまで受け持ってしまい、
  下のアプリを開いた瞬間、その中身が上のアプリの保存版として上書きされる。
- **保存版の片づけは、自分の名前で始まるものだけ。**
  「自分以外を全部消す」と書くと、隣のアプリの保存版まで消してしまう
  （`keisanki-` は `keisanki-` だけ、`denpa-` は `denpa-` だけ消す）。
- 直したら、中の版数（`keisanki-v3` の数字）を1つ増やす。
- 測定などで「毎回ほんとうに取りに行きたい」ファイルは、保存版で答えないよう除外する
  （電波マップの `ping.txt` がこれ）。

## 出す前に確かめること

パソコンの中で `python -m http.server` を立て、本物のブラウザで押して確かめる。

- **`127.0.0.1` ではなく `localhost` で開く。**
  `127.0.0.1` だと裏方が登録されず、確認になっていない。
- 主な操作をひととおり（作る・消す・元に戻す）
- 閉じて開き直しても内容が残るか
- **画面の写真を撮って、目で見る**（電波マップの色ぬりの粗さは、コードを読むだけでは気づけなかった）
- 既存アプリを壊していないか（計算機で 7×8=56 を確認する）
- 電波を切っても開けるか、2本のアプリの保存版が共存するか

自動で確かめるときは Playwright を使い、iPhone の画面サイズで開く。
（この作業環境では `/opt/pw-browsers/chromium-1194/chrome-linux/chrome` を指定する）

**手元での結果は、本番と条件が違う。** 電波マップを手元のサーバーで測ると
返事が3msで常に満点になった。「測れている」であって「正しい」ではない。

## 分かったこと（次に作るときのメモ）

- 1枚のHTMLだけでも、iPhone のホーム画面に置けるアプリの形にはできる。
- 見た目を「アプリらしく」する肝は、①画面いっぱいに広げる ②ボタンを大きく丸く ③押した瞬間に色が変わること。
- 「電波がなくても開ける」ようにするには、安全な接続（https）か、パソコン自身での表示が必要。
- **1つの置き場に何本もアプリを入れられる。** フォルダを分ければ、別アプリとしてホーム画面に追加できる。
- **ブラウザからは、できないことがある。** Wi-Fiの電波強度、電池の残り、位置の細かい追跡などは
  ウェブページからは読めない。「近いことを別の方法で測る」か「手で入れてもらう」で回り込む。
