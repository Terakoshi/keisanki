# 計算機（keisanki）

PWA（ブラウザで動き、iPhone のホーム画面に置けるウェブアプリ）の練習として作った計算機。
アプリ開発の1本目・お試し用。

作成: 2026-08-25

## できること

- 足す・引く・かける・わる、％、プラスマイナスの切り替え、小数点
- 「AC」で全部消す／数字を入れた後は「C」でその数だけ消す
- **表示部分を左になぞる**と、1文字だけ消える（打ち間違いの取り消し）
- **表示部分を軽くたたく**と、答えをコピーする
- パソコンではキーボードでも打てる（数字 / + - * / / Enter＝イコール / Backspace＝1文字消す / Esc＝全消し）
- 0で割ったら「エラー」と出る（何か押すと元に戻る）
- 桁が多いときは自動で文字を小さくして、3桁ごとにカンマを付ける

## ファイルの中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。見た目も計算も全部この1枚に入っている |
| `manifest.webmanifest` | ホーム画面に置いたときの名前・色・アイコンの設定 |
| `sw.js` | 電波がなくても開けるようにする裏方 |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン画像 |

## 動かし方

### パソコンで見るだけ

`index.html` をダブルクリックする（ブラウザで開く）。計算はこれで全部できる。

### iPhone のホーム画面に置く

1. iPhone の **Safari** で https://terakoshi.github.io/keisanki/ を開く
2. 下の共有ボタン → 「ホーム画面に追加」

アイコンが並び、タップするとアドレスバーのないアプリのように開く。https なので「電波がなくても開ける」機能も働く。

### （参考）パソコンから直接配る方法

公開したくない試作を iPhone で見たいときは、同じWi-Fiのパソコンから配れる。

```
python -m http.server 8000 --directory "C:\Users\terak\claude_workspace\work\副業\apps\keisanki"
```

`ipconfig` で調べたIPアドレスを使って、iPhone の Safari で `http://そのIP:8000` を開く。
**ただし iPhone 側の設定で「安全でない接続（http）」が拒否されることがある**（2026-08-25 に実際に詰まった）。
その場合は上の GitHub Pages 方式を使うほうが早い。

## 分かったこと（次に作るときのメモ）

- 1枚のHTMLだけでも、iPhone のホーム画面に置けるアプリの形にはできる。
- 見た目を「アプリらしく」する肝は、①画面いっぱいに広げる ②ボタンを大きく丸く ③押した瞬間に色が変わること。
- 「電波がなくても開ける」ようにするには、安全な接続（https）か、パソコン自身での表示が必要。
